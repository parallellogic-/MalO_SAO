# JLCPCB Assembly Guide

## BOM Format
The included BOM CSV is formatted for JLCPCB SMT assembly service.

## LCSC Parts
All passive components use JLCPCB basic parts from LCSC for lowest assembly cost.

### Component Notes:
- **Resistors**: 0402, 1%, 1/16W
- **Capacitors**: 0402, C0G/NPO dielectric for stability

## How to Order
1. Upload Gerbers to JLCPCB
2. Enable SMT Assembly
3. Upload this BOM CSV
4. Map designators to LCSC parts
5. Review and order!
